---

## 🔍 Обзор

**AI Web Translator** решает главную проблему традиционных браузерных переводчиков (таких как Google Translate или DeepL): поломку верстки, сбой реактивного состояния компонентов React/Vue, потерю обработчиков событий и зависание выпадающих списков.

Работая исключительно с `TextNode.nodeValue` и атрибутами живого DOM, расширение переводит страницы нативно, не перерисовывая и не нарушая структуру элементов интерфейса.

- **Свобода выбора нейросетей**: Подключайтесь напрямую к Google Gemini, OpenAI, Anthropic Claude, DeepSeek, Groq, OpenRouter или работайте полностью офлайн через Ollama, LM Studio и vLLM.
- **Отказоустойчивость с мультипрофилями**: Создавайте независимые профили настроек. При исчерпании квоты или лимита запросов (HTTP 429) расширение автоматически переключается на следующий профиль и продолжает перевод без прерывания.
- **Нативная локализация интерфейса (i18n)**: Язык интерфейса расширения автоматически адаптируется под язык вашего браузера (русский, английский, упрощенный китайский).

## 🚀 Ключевые возможности

### 1. 🛡️ 100% безопасный движок перевода DOM
- Изменяет **только** значение `TextNode.nodeValue`, не модифицируя дерево DOM и не затрагивая стили CSS.
- Внутренние ссылки React fiber, реактивные прокси Vue и зоны Angular остаются абсолютно целыми.
- Корректно распознает всплывающие подсказки, модальные окна и порталы (`.semi-portal`, `.ant-popover`).

### 2. 🤖 Универсальная поддержка нейросетей и провайдеров
- **Google Gemini Cloud**: официальный OpenAI-совместимый эндпоинт с быстрой моделью по умолчанию `gemini-3.5-flash-lite`.
- **Anthropic Claude**: нативный адаптер Claude API (`/v1/messages`) с поддержкой Claude 3.5 Sonnet и Haiku.
- **DeepSeek API**: поддержка моделей `deepseek-chat` (DeepSeek-V3) и `deepseek-reasoner` (DeepSeek-R1).
- **OpenAI**: официальные модели `gpt-4o-mini`, `gpt-4o` и любые совместимые шлюзы.
- **Groq Cloud**: сверхбыстрый инференс на процессорах LPU (`llama-3.3-70b-versatile`).
- **Локальные офлайн-модели**: Ollama (`localhost:11434`), LM Studio (`localhost:1234`), vLLM, LocalAI.
- **Агрегаторы и прокси**: OpenRouter, Mistral AI и собственные корпоративные обратные прокси.

### 3. 👥 Управление профилями и авторотация при лимитах
- **Именованные профили**: создавайте отдельные профили для разных задач (*"Gemini Flash"*, *"DeepSeek V3"*, *"Ollama Local"*, *"OpenAI Backup"*), каждый со своим URL, ключом, моделью и размером пачки.
- **Быстрое переключение**: выбирайте активный профиль прямо из выпадающего списка в окне расширения.
- **Умная авторотация при 429**: если текущий API возвращает ошибку исчерпания лимита (`RESOURCE_EXHAUSTED`, `insufficient_quota`, `rate_limit_exceeded`), расширение автоматически переключается на следующий профиль и продолжает перевод.
- **Импорт / Экспорт JSON**: скачивайте все сохраненные профили в файл с датой (`ai_translator_profiles_YYYY-MM-DD.json`) и мгновенно восстанавливайте их на других устройствах.

### 4. 🌐 Автоопределение языка и нативная локализация (i18n)
- **Автоматическая локализация интерфейса**: меню, кнопки и служебные уведомления открываются на языке вашего браузера (`RU`, `EN`, `ZH`).
- **Автоопределение исходного языка**: по умолчанию исходный язык страницы установлен в **Авто (AUTO)**.
- **Языки перевода**: поддержка перевода на русский (RU), английский (EN), китайский (ZH), испанский (ES), немецкий (DE), японский (JA) и французский (FR).

### 5. 👁️ Перевод только видимой области экрана (Viewport-Only)
- Переводятся только те блоки, которые видны пользователю на экране прямо сейчас.
- Элементы за пределами экрана регистрируются через `IntersectionObserver` и переводятся постепенно по мере прокрутки страницы, что экономит до 80% токенов.

### 6. ⚡ Двухуровневое быстрое кэширование
- **Оперативная память (`pageCache`)**: мгновенная вставка повторно встречающихся пунктов меню, кнопок и меток без повторных сетевых вызовов.
- **Постоянный LRU-кэш**: хранит до 5000 уникальных переводов в `chrome.storage.local`.
- **Дедупликация внутри пачки**: одинаковые текстовые фрагменты на странице упаковываются и отправляются в модель лишь один раз.

### 7. 🪟 Интерактивный плавающий виджет
- **Индикатор состояния и счетчик**: отображает статус перевода, количество обработанных элементов и имя активного профиля.
- **Кнопка «Оригинал» / «Перевод»**: моментальное переключение между переведенным и оригинальным текстом страницы без перезагрузки вкладки.
- **Кнопка обновления (`⟳`)**: принудительное сканирование и перевод динамически появившихся элементов (AJAX, бесконечные ленты, комментарии).
- **Кнопка закрытия (`✕`)**: скрывает виджет со страницы.

## 📥 Установка

### Вариант 1: Быстрый установщик в 1 клик для Windows (Рекомендуется)

1. Скачайте репозиторий и дважды нажмите на файл **`install.bat`**.
2. В появившемся интерактивном меню:
   - **`[1] Скопировать путь в буфер обмена (без открытия браузера)`**: подготавливает файлы и копирует путь `%LOCALAPPDATA%\AI-Translator\extension` в буфер обмена для быстрой вставки через `Ctrl + V` в проводнике выбора папки.
   - **`[2] Установить в браузер`**: копирует файлы, открывает папку расширения в Проводнике и показывает удобную подсказку со ссылками на страницы расширений (`chrome://extensions`, `edge://extensions`).
   - **`[3] Прямой запуск браузера с расширением`**: мгновенно запускает браузер с параметром `--load-extension` для быстрого тестирования.
   - **`[4] Собрать релизный ZIP-архив`**: собирает чистый релизный архив `dist/AI-Translator-v1.0.0.zip`.
   - **`[5] Удалить расширение из AppData`**: очищает установленную копию из папки пользователя.

### Вариант 2: Ручная установка (Любая операционная система)

1. **Склонируйте репозиторий**:
   ```bash
   git clone https://github.com/Onarous/ai-web-translator.git
   ```
2. **Откройте страницу расширений** в вашем Chromium-браузере:
   - Google Chrome: `chrome://extensions/`
   - Microsoft Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
   - Яндекс Браузер: `browser://extensions/`
3. Включите переключатель **«Режим разработчика»** (Developer mode) в верхнем правом углу.
4. Нажмите кнопку **«Загрузить распакованное»** (Load unpacked) и выберите директорию репозитория (или папку `dist/extension`).

### Удаление расширения
- Запустите **`uninstall.bat`** для быстрой очистки файлов расширения из `AppData`, после чего нажмите «Удалить» в списке расширений браузера.

## ⚙️ Инструкция по использованию

### Быстрый старт
1. Откройте любую страницу в браузере.
2. Нажмите на иконку **AI Web Translator** на панели расширений.
3. Выберите языковую пару (например, **"Авто (AUTO) → Русский (RU)"**).
4. Нажмите **"Перевести страницу"**.

### Настройка профилей и авторотация
1. В окне расширения нажмите **"Настройки API"**, чтобы открыть блок конфигурации.
2. В разделе **"Профили конфигурации"**:
   - Выберите существующий профиль из списка или нажмите **"➕ Новый"**.
   - Укажите имя профиля, URL API, ключ доступа, название модели и размер пачки, затем нажмите **"💾 Сохранить"**.
   - Активируйте галочку **"Авторотация при исчерпании лимитов"**: если активный ключ получит ошибку превышения лимитов (HTTP 429), расширение автоматически перейдет к следующему профилю.
3. **Резервное копирование и перенос**:
   - Нажмите **"📤 Экспорт JSON"**, чтобы сохранить все ваши профили в отдельный файл.
   - Нажмите **"📥 Импорт JSON"**, чтобы восстановить конфигурацию на любом другом ПК.

### Управление плавающим виджетом
Когда запускается процесс перевода, в нижнем правом углу страницы появляется плавающий виджет:
- **Индикатор и счетчик**: показывает текущий прогресс перевода и название активного профиля.
- **«Оригинал» / «Перевод»**: моментально переключает текст страницы между переводом и оригиналом без обновления страницы.
- **«⟳» (Обновить)**: запускает сканирование и перевод новых динамических блоков (AJAX, комментарии, ленты).
- **«✕» (Закрыть)**: закрывает виджет.

## 🔒 Безопасность и конфиденциальность

- **Никакой сторонней телеметрии**: в расширении полностью отсутствуют внешние скрипты аналитики, трекеры и реклама.
- **Прямое соединение с API**: запросы уходят исключительно и напрямую по адресу, указанному в вашем активном профиле.
- **Маскирование логов**: токены авторизации (`Bearer ***`, `sk-***`) автоматически скрываются маской в консоли браузера.
